# Модели для Creality K1C

Бесплатные 3D-модели для печати на Creality K1C — и на любом другом принтере с подходящим столом. У каждой модели здесь лежат проект для слайсера (3mf), исходный код генератора, картинки с размерами и описание с историей версий. У некоторых моделей есть варианты — выбирайте подходящий.

- [REGISTRY.md](REGISTRY.md) — все модели
- [FILAMENTS.md](FILAMENTS.md) — нити в наличии
- [AGENT.md](AGENT.md) — как устроен проект и правила для ИИ-агента
