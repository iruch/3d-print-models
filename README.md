# Модели для 3D-печати

Бесплатные модели для печати на любом 3D-принтере, на стол которого они помещаются, от любого производителя. У каждой модели есть файл для печати (3mf), картинки с размерами, описание, список подходящих принтеров и нитей, история версий и исходный код генератора. У некоторых моделей есть варианты — выбирайте подходящий.

## Как напечатать

1. Найдите модель в [реестре](REGISTRY.md) и откройте её страницу.
2. Посмотрите раздел «Совместимость»: помещается ли модель на ваш принтер и какой нитью её лучше печатать. Если вашего принтера нет в списке, сравните нужный размер стола с областью печати своего принтера.
3. Скачайте файл `.3mf` из папки нужной версии. На GitHub: открыть файл → кнопка «Download raw file».
4. Откройте его в слайсере своего принтера: Creality Print, Bambu Studio, OrcaSlicer, PrusaSlicer, Cura и т. п. В файле только геометрия, поэтому настройки печати берутся из профиля вашего принтера и нити. Рекомендации по слою, заполнению и поддержкам есть на странице модели.

## Что здесь есть

- [REGISTRY.md](REGISTRY.md) — все модели
- [PRINTERS.md](PRINTERS.md) — справочник принтеров, по которому считается совместимость
- [FILAMENTS.md](FILAMENTS.md) — нити, которые есть у автора
- [AGENT.md](AGENT.md) — как устроен проект и правила для ИИ-агента

Модели проверяются печатью на Creality K1C. Что именно проверено, указано на странице каждой модели.
